## Idea
People use multiple disconnected platforms to discover, manage and attend events, while lacking real-time information about event changes and venue conditions or a way to connect with more people that attend the events they have interested on. Crowded is a platform where we try to give an answer to these problems.

## Main Features
Here are the main features that came up with the idea:
- recommend events based on the user’s location (and the radius they have set) and their musical tastes
- allow organisers to run polls (e.g. announce an artist and let users indicate they’re interested, so the organiser can work out whether they need a larger or smaller venue for the concert and manage other logistics on their end, such as drinks for e.g.)
- Users can upload their tickets to the app so that everything is centralised and also contribute towards achievements (e.g. achievements for attending 10, 100 or 1,000 concerts, and others)
- Organisers can record changes to the event (e.g. cancelled, date changed, etc.) to notify the interested users.
- Users attending an event can report, for example, if it’s very crowded (e.g. at a museum, so that other users interested in attending the museum event can decide whether or not to go, given that it’s very crowded)
- Users can review the event
- Users can connect with people who share similar preferences
- Users can connect with people attending the same event they’re interested in

More features can be added later, but these ones are the ones we consider the most important in which there's some feature that are more important for an MVP than others.
