## Context
Based on the Crowded project documentation and the assignment, my team is preparing the Security and Privacy Assessment section for the Sprint 1 report. The assessment should reflect the planned product and design described in our documents.

## Goal
Create a concise Security and Privacy Assessment in English. It must cover:

- Initial Threat Model
- Sensitive Data
- Access-Control Requirements
- Data-Minimization Measures
- Retention Considerations

## Instructions
Carefully review the assignment and the relevant project documents before writing, especially the Data Model. Use only information available in these sources.

- For the Initial Threat Model, identify the system scope, assets and trust boundaries. Present project-specific threats using a STRIDE table and link them to the documented requirements or architecture decisions.
- For the other sections, use tables when they make the information clearer. Include relevant requirement identifiers and links to source documents.
- Do not invent threats, data, controls, integrations or retention periods.
- Keep the assessment focused, concise and consistent with the other project documents.
